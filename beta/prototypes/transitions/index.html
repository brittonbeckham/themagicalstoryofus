How it would be built

Arriving at a section

Every option except “Today” moves the new page to the Readings section before revealing it, so the page appears already in place, and the section’s gold hairline draws in once it settles.

On the real site the visible scroll comes from smooth scrolling being switched on for the whole page, which also smooths the browser’s jump to the section on arrival. The fix is to keep scrolling instant while the page loads and switch smooth scrolling on afterward (for clicks within the same page). With the browser’s built-in page transitions, the new page is captured after that instant jump, so the reveal starts already in place.

Your device asks for reduced motion, so every option plays as a quick crossfade. Untick “Reduced motion” to preview the full effects.
